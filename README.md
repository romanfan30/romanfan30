### Ключевые проекты

#### 1. [Library Management System](https://github.com/romanfan30/library-management-system) — REST API сервис управления библиотечным фондом
* **Тип:** Backend Web Service
* **Стек:** Java 17, Spring Boot, Spring Web MVC, Spring Data JPA (Hibernate), Spring Security, PostgreSQL, H2, JUnit 5, Mockito, Maven.
* **Реализация:**
  * Спроектирована многослойная архитектура (`Controller` → `Service` → `Repository`) и схема БД из 5 связанных сущностей (`Book`, `Author`, `Category`, `User`, `Loan`) с контролем статусов выдачи (`ACTIVE`, `RETURNED`, `OVERDUE`).
  * Разработан REST API с фильтрацией, поиском и валидацией (`Bean Validation`); применён паттерн DTO для защиты чувствительных данных (исключение хэшей паролей из HTTP-ответов).
  * Настроена аутентификация через Spring Security (`BCryptPasswordEncoder`, кастомный `UserDetailsService`) с корректной обработкой неавторизованных REST-запросов (`401 Unauthorized`).
  * Реализовано предзаполнение БД через `CommandLineRunner` с изоляцией профилей (`@Profile("!test")`) и написано **50 автотестов** (unit-тесты на Mockito, тесты репозиториев на H2 через `@DataJpaTest` и интеграционные тесты `MockMvc`).

#### 2. [Custom MJPG Image Codec](https://github.com/romanfan30/aisd_4sem_lab2) — Кодек сжатия изображений с потерями (JPEG-пайплайн)
* **Тип:** Низкоуровневая обработка данных и алгоритмы
* **Стек:** Python, NumPy, Pillow, Matplotlib.
* **Реализация:**
  * Разработан сквозной цикл JPEG-подобного кодека с упаковкой в собственный бинарный формат (`.mjpg` v2): конвертация $RGB \leftrightarrow YCbCr$, прореживание каналов цветности ($2\times$), разбиение на блоки $8 \times 8$ и динамическое масштабирование таблиц квантования ($Q \in [1, 100]$).
  * Оптимизировано 2D дискретное косинусное преобразование (ДКП / IDCT) через матричное умножение ($C \cdot B \cdot C^T$), что ускорило вычисление блока в **8 раз** (снижение сложности с $O(N^4)$ до $O(N^3)$).
  * Реализованы Zigzag-обход, разностное кодирование DC, RLE для AC-коэффициентов (с маркерами `EOB`/`ZRL`), кодирование переменной длины (VLC) и битовая упаковка по алгоритму Хаффмана.

#### 3. [Lossless Compression Cascades](https://github.com/romanfan30/algorithms_lab_1) — Многоступенчатые каскады сжатия данных без потерь
* **Тип:** Теория информации и прикладные алгоритмы
* **Стек:** Python, NumPy, Matplotlib.
* **Реализация:**
  * С нуля (без сторонних библиотек) реализованы 10 фундаментальных алгоритмов: **RLE**, **MTF**, **Хаффман**, **Канонический Хаффман**, **Арифметическое кодирование**, **BWT** (через суффиксный массив Манбера–Майерса), **LZ77**, **LZSS**, **LZ78** и **LZW**.
  * Собраны и протестированы 9 комбинированных каскадов (`BWT + MTF + RLE + HA`, `LZSS + HA` и др.) на сырых изображениях (`.raw`), текстах, исполняемых файлах (`.exe`) и корпусе `enwik7`; достигнуто сжатие до **32.2×** на графике и до **3.1×** на текстах.

#### 4. [Self-Balancing Search Trees Benchmark](https://github.com/romanfan30/algorithms_lab_2) — Анализ сбалансированных деревьев поиска (BST, AVL, RB)
* **Тип:** Алгоритмы и структуры данных
* **Стек:** Python, Matplotlib.
* **Реализация:**
  * С нуля реализованы **BST**, **АВЛ-дерево** и **красно-чёрное дерево (RB)** (вставка, удаление, 4 вида обхода, малые и большие повороты, перекраска узлов и балансировка чёрной высоты).
  * Проведено нагрузочное тестирование ($n = 30\,000$ элементов) на случайных и монотонно возрастающих данных, экспериментально подтвердившее логарифмические верхние оценки высоты для АВЛ ($h \le 1.44\log_2(n+1)$) и RB-деревьев ($h \le 2\log_2(n+1)$).
